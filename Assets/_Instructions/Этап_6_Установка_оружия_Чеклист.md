# Чеклист: Установка системы оружия

Этот документ содержит полный пошаговый чеклист для установки системы оружия на основе уроков 6.1–6.4.

---

## ✅ Шаг 1: WeaponData (ScriptableObject)

**Цель:** Создать ScriptableObject с данными оружия.

### 1.1. Создание скрипта WeaponData
- [ ] В папке `Assets/_Scripts/Weapons/` создан скрипт `WeaponData.cs`
- [ ] Класс наследуется от `ScriptableObject` (не `MonoBehaviour`)
- [ ] Добавлен атрибут `[CreateAssetMenu]` с меню `"Game Data/Weapon Data"`
- [ ] Поля: `weaponName`, `weaponType`, `icon`, `damage`, `attackSpeed`, `range`, `knockbackForce`, `attackAnimationName`, `attackSound`, `projectilePrefab`

### 1.2. Создание ассетов WeaponData
- [ ] В папке `Assets/_ScriptableObjects/Weapons/` созданы ассеты:
  - [ ] `Weapon_Sword_Default` (Melee, Damage: 20, Speed: 1.2, Range: 2)
  - [ ] `Weapon_Bow_Default` (Ranged, Damage: 15, Speed: 1.0, Range: 12)
  - [ ] `Weapon_Staff_Default` (Magic, Damage: 10, Speed: 0.8, Range: 10)

---

## ✅ Шаг 2: WeaponBase (базовый класс)

**Цель:** Создать абстрактный базовый класс для всех видов оружия.

### 2.1. Создание скрипта WeaponBase
- [ ] В папке `Assets/_Scripts/Weapons/` создан скрипт `WeaponBase.cs`
- [ ] Класс помечен как `abstract` и наследуется от `MonoBehaviour`
- [ ] Поля: `weaponData` (WeaponData), `owner` (Transform)
- [ ] Свойства: `Damage`, `Range`, `AttackSpeed` (геттеры к `weaponData`)
- [ ] Методы:
  - [ ] `CanAttack()` — проверка перезарядки
  - [ ] `StartAttackCooldown()` — запуск задержки
  - [ ] `Attack()` — абстрактный метод

---

## ✅ Шаг 3: MeleeWeapon (оружие ближнего боя)

**Цель:** Создать класс для ближнего боя и его префаб.

### 3.1. Создание скрипта MeleeWeapon
- [ ] В папке `Assets/_Scripts/Weapons/` создан скрипт `MeleeWeapon.cs`
- [ ] Класс наследуется от `WeaponBase`
- [ ] Поля: `attackOrigin` (Transform), `hitRadius` (float), `hitLayers` (LayerMask)
- [ ] Реализован метод `Attack()` с использованием `Physics.OverlapSphere`
- [ ] Добавлен `OnDrawGizmosSelected()` для визуализации радиуса удара в редакторе

### 3.2. Создание префаба меча
- [ ] В сцене создан пустой объект `Sword_Melee`
- [ ] Добавлен компонент `MeleeWeapon`
- [ ] Создан дочерний объект `AttackOrigin` и назначен в поле `Attack Origin`
- [ ] В Inspector настроено:
  - [ ] `Weapon Data` → `Weapon_Sword_Default`
  - [ ] `Hit Radius` → `1.5` (или другое значение)
  - [ ] `Hit Layers` → слой `Enemy` (или другие слои)
- [ ] Префаб сохранён в `Assets/_Prefabs/Weapons/Sword_Melee.prefab`
- [ ] Объект удалён из сцены (если был создан там)

---

## ✅ Шаг 4: Projectile (снаряд)

**Цель:** Создать базовый класс снаряда и его префаб.

### 4.1. Создание скрипта Projectile
- [ ] В папке `Assets/_Scripts/Weapons/` создан скрипт `Projectile.cs`
- [ ] Поля: `speed`, `maxDistance`, `damage`, `hitLayers`
- [ ] В `Update()` реализовано движение вперёд и проверка дистанции
- [ ] В `OnTriggerEnter()` реализована проверка слоёв и логирование попаданий

### 4.2. Создание префаба снаряда
- [ ] В сцене создан пустой объект `Arrow_Projectile` (или другое имя)
- [ ] Добавлены компоненты:
  - [ ] `Projectile`
  - [ ] `SphereCollider` (или другой Collider) с галочкой **Is Trigger**
  - [ ] (опционально) `Rigidbody` с `Is Kinematic = true`
- [ ] В Inspector настроено:
  - [ ] `Speed` → `20`
  - [ ] `Max Distance` → `20`
  - [ ] `Damage` → `10` (будет переопределяться из оружия)
  - [ ] `Hit Layers` → слой `Enemy`
- [ ] Префаб сохранён в `Assets/_Prefabs/Weapons/Projectile.prefab` (или `Projectile_Arrow.prefab`)
- [ ] Объект удалён из сцены

### 4.3. Связывание снаряда с WeaponData лука
- [ ] Открыт ассет `Weapon_Bow_Default`
- [ ] В поле `Projectile Prefab` назначен префаб `Projectile` (из шага 4.2)

---

## ✅ Шаг 5: RangedWeapon (оружие дальнего боя)

**Цель:** Создать класс для дальнего боя и его префаб.

### 5.1. Создание скрипта RangedWeapon
- [ ] В папке `Assets/_Scripts/Weapons/` создан скрипт `RangedWeapon.cs`
- [ ] Класс наследуется от `WeaponBase`
- [ ] Поля: `shootOrigin` (Transform), `projectileSpeedOverride` (float), `projectileHitLayers` (LayerMask)
- [ ] Реализован метод `Attack()`:
  - [ ] Проверка наличия `weaponData.projectilePrefab`
  - [ ] Создание экземпляра снаряда через `Instantiate`
  - [ ] Настройка параметров снаряда (damage, maxDistance, hitLayers, speed)

### 5.2. Создание префаба лука
- [ ] В сцене создан пустой объект `Bow_Ranged`
- [ ] Добавлен компонент `RangedWeapon`
- [ ] Создан дочерний объект `ShootOrigin` и назначен в поле `Shoot Origin`
- [ ] В Inspector настроено:
  - [ ] `Weapon Data` → `Weapon_Bow_Default`
  - [ ] `Projectile Hit Layers` → слой `Enemy`
  - [ ] `Projectile Speed Override` → `0` (или другое значение, если нужно)
- [ ] Префаб сохранён в `Assets/_Prefabs/Weapons/Bow_Ranged.prefab`
- [ ] Объект удалён из сцены

---

## ✅ Шаг 6: WeaponManager (управление оружием игрока)

**Цель:** Подключить систему оружия к игроку.

### 6.1. Создание скрипта WeaponManager
- [ ] В папке `Assets/_Scripts/Weapons/` создан скрипт `WeaponManager.cs`
- [ ] Поля (все `[SerializeField] private`): `playerStats` (PlayerStats), `defaultWeaponPrefab` (WeaponBase), `weaponSocket` (Transform); текущее оружие — приватное поле `currentWeapon`, доступ снаружи только через свойство `CurrentWeapon` (только чтение)
- [ ] В `Awake()`:
  - [ ] Автопоиск `PlayerStats` через `GetComponent`, если не назначен
  - [ ] Проверка: если `defaultWeaponPrefab == null` — `Debug.LogError` и выход
  - [ ] Всегда вызывается `EquipNewWeapon(defaultWeaponPrefab)` — игрок при старте экипируется явно заданным оружием по умолчанию
- [ ] В `OnEnable()` / `OnDisable()` подписка/отписка на событие `InputManager.Instance.OnAttackPressed`
- [ ] Методы:
  - [ ] `HandleAttackPressed()` — вызывает `currentWeapon.Attack()`
  - [ ] `EquipNewWeapon()` — экипирует новое оружие из префаба
  - [ ] `SetupWeapon()` — настраивает владельца и позицию оружия

### 6.2. Подключение WeaponManager к Player
- [ ] Открыт префаб `Player` (см. урок 5.4)
- [ ] Создан дочерний объект `WeaponSocket` внутри `Player`
- [ ] На объект `Player` добавлен компонент `WeaponManager`
- [ ] В Inspector `WeaponManager` настроено:
  - [ ] `Player Stats` → можно оставить пустым (автопоиск)
  - [ ] `Weapon Socket` → перетащен объект `WeaponSocket`
  - [ ] `Default Weapon Prefab` → перетащен префаб `Sword_Melee` (обязательно; при старте игрок всегда экипируется этим оружием)
- [ ] Префаб `Player` сохранён

---

## ✅ Шаг 7: Проверка работы

**Цель:** Убедиться, что система оружия работает корректно.

### 7.1. Проверка в редакторе
- [ ] Префаб `Player` содержит компонент `WeaponManager`
- [ ] У `WeaponManager` назначен `Weapon Socket` и `Default Weapon Prefab`
- [ ] Префаб `Sword_Melee` содержит компонент `MeleeWeapon` с назначенным `WeaponData`
- [ ] Префаб `Bow_Ranged` содержит компонент `RangedWeapon` с назначенным `WeaponData`
- [ ] В `WeaponData` лука назначен префаб `Projectile`

### 7.2. Проверка в игре
- [ ] Запущена игра через `Bootstrap`
- [ ] Переход в `GameScene` через главное меню
- [ ] При старте игры:
  - [ ] У игрока в иерархии появился экземпляр меча под `WeaponSocket` (текущее оружие задаётся только кодом из `Default Weapon Prefab`, в инспекторе отдельного поля «Current Weapon» нет)
- [ ] При нажатии кнопки атаки (ЛКМ / X на геймпаде):
  - [ ] В консоли появляются логи о ближней атаке
  - [ ] Если рядом есть объекты на слое `Enemy`, логируется попадание
- [ ] При смене оружия на лук:
  - [ ] При атаке создаётся снаряд
  - [ ] Снаряд летит вперёд и логирует попадания

---

## 📝 Примечания

- **Порядок выполнения важен:** выполняй шаги последовательно, не пропускай этапы.
- **Тестирование:** проверяй работу после каждого шага, особенно после шага 7.
- **Слои:** убедись, что слой `Enemy` создан в `Project Settings` → `Tags and Layers`.
- **Input System:** убедись, что `InputManager` настроен и содержит действие `Attack` (см. Этап 3).
